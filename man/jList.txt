NAME
    jList - directory listing with eza

SYNOPSIS
    jList [options] [eza-args]

    Options:
      -h, --help      Show this help
      -v, --version   Show version
      -a, --all       Include hidden files and dotfiles

    Any additional argument is forwarded directly to eza.

DESCRIPTION

Runs eza in long format with binary sizes, headers, colors, git status
per file, repository summaries, icons, hyperlinks, and ISO timestamps.
When run in the home directory without --all, the standard clutter
(Music, Movies, Pictures, Videos, Applications, Desktop, Library) is
hidden from the listing. All extra arguments are passed to eza
unchanged.

EXAMPLES

    jList
        List the current directory.

    jList -a
        Include hidden files and dotfiles.

    jList ~/Downloads
        List a specific directory.
