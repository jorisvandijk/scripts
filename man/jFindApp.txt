NAME
    jFindApp - search for an app across App Store, Homebrew, and Nix

SYNOPSIS
    jFindApp [options] <name>

    Options:
      -h, --help      Show this help
      -v, --version   Show version

DESCRIPTION

Searches for <name> in the Mac App Store (via mas), Homebrew (brew search),
and Nix (nix search nixpkgs), and prints a one-line summary per store.
Nix results are filtered to packages available on the current platform.
Requires mas, brew, and nix to all be installed.

Each result is color-coded: green for an exact match, yellow for close but
not exact matches, red when nothing is found.

Note: Nix searches may be slow. The first run fetches the package index;
subsequent runs perform a platform-availability check per result.

EXAMPLES

    jFindApp firefox
        Search all three stores for "firefox".

    jFindApp iterm
        Search all three stores for "iterm".

KEYWORDS

    install, search, find, application, app store, homebrew, software
