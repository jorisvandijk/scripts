NAME
    jBlog - write and publish a Hugo blog post

SYNOPSIS
    jBlog [options]

    Options:
      -h, --help      Show this help
      -v, --version   Show version

DESCRIPTION

Full write-to-publish workflow for the Hugo blog at ~/git/website. Uses
Zed (zeditor) as the editor — $EDITOR is not used.

Running jBlog creates a new draft at content/posts/untitled-<timestamp>.md,
starts a Hugo dev server, and opens the draft URL in the browser. If an
untitled-*.md file already exists in content/posts/, that draft is resumed
instead of creating a new one.

Close the Zed window when done writing. The script then:

  1. Prompts for the post title (loops until non-empty).
  2. Renames the draft to content/posts/<slug>.md, sets draft: false,
     and updates the timestamp.
  3. Opens an fzf multi-select picker of existing post tags; select any
     that apply. Then prompts for additional free-form tags
     (space-separated; Enter to skip).
  4. Asks whether to push to git (default: N). If confirmed, stages the
     post file, commits with "Add post: <title>", and pushes.

Interrupting the script (Ctrl+C) at any point kills the Hugo server and
leaves the draft intact for the next session.

EXAMPLES

    jBlog
        Start a new post or resume the in-progress draft.

KEYWORDS

    write, post, article, hugo, publish, draft, blog
