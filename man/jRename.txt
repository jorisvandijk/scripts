NAME
    jRename - rename files in current directory: lowercase, spaces and underscores to hyphens

SYNOPSIS
    jRename [options]

    Options:
      -h, --help      Show this help
      -v, --version   Show version

DESCRIPTION

Renames every file and directory in the current directory using three
transformations applied in order:

  1. Lowercase   — the entire filename is converted to lowercase.
  2. Spaces      — every space is replaced with a hyphen.
  3. Underscores — every underscore is replaced with a hyphen.

Items whose name is already correct are silently skipped. If the computed new
name conflicts with an existing entry, it is skipped with a warning.

EXAMPLES

    jRename
        Rename all files and directories in the current directory.

KEYWORDS

    rename, lowercase, label, new name, hyphen, underscore
