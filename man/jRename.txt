NAME
    jRename - rename files in current directory: lowercase, spaces to hyphens, underscores interactively

SYNOPSIS
    jRename [options]

    Options:
      -h, --help      Show this help
      -v, --version   Show version

DESCRIPTION

Renames every file in the current directory using three transformations applied
in order:

  1. Lowercase  — the entire filename is converted to lowercase.
  2. Spaces     — every space is replaced with a hyphen.
  3. Underscores — each underscore is presented to you one at a time, left to
                   right. The underscore is highlighted in the filename so you
                   can see its position at a glance. Press [a] to replace it
                   with a hyphen or [b] to keep it as an underscore.

Files whose name is already correct are silently skipped. If the computed new
name conflicts with an existing file, that file is skipped with a warning.

EXAMPLES

    jRename
        Rename all files in the current directory interactively.
