NAME
    j - j-scripts shared library and CLI tooling

SYNOPSIS
    j [command] [args]

    Commands:
      (none)            Open the interactive script picker (requires fzf)
      list              List all available j-scripts with descriptions
      new <jName>       Create a new script from the standard template
      man <jName>       Open the man page for a script in $PAGER
      newman <jName>    Create a new man page stub for a script
      help              Show the command list

    Options:
      -h, --help      Show this help
      -v, --version   Show version

DESCRIPTION

Every j-script sources j at startup. The library provides the logging
helpers (j::info, j::warn, j::error, j::die), plain output (j::msg),
inline prompts (j::prompt), y/n confirmation (j::confirm), version
printing, man page display, dependency checking (j::require), OS
detection (j::os), the editor/discard flow (j::edit_or_discard), and
three fzf picker helpers (j::pick, j::pick_table, j::pick_files).
Run directly, j acts as a small CLI for managing the collection.

FZF PICKERS

All three helpers share a common house style defined in J_FZF_STYLE.
The input label is set automatically to " jSuite · <script-name> ".

    j::pick "prompt" single|multi
        Plain line picker. Reads lines from stdin. The second argument
        must be the literal word "single" or "multi".

        Example:
            printf 'foo\nbar\nbaz\n' | j::pick "Choose" single

    j::pick_table "prompt" "col_spec" single|multi ["preview_cmd"]
        Tab-delimited table picker. col_spec is a --with-nth spec
        (e.g. "1,2" or "1,2,3") controlling which columns are
        displayed. An optional fourth argument enables a preview pane.

        Example:
            printf 'id\tLabel\tMeta\n' | j::pick_table "Item" "1,2" single

    j::pick_files ["prompt"]
        Multi-select file picker with bat preview. Searches from the
        current directory. Prompt defaults to "Files".

        Example:
            mapfile -t FILES < <(j::pick_files "Open")
            micro "${FILES[@]}"

Running j with no arguments opens an fzf picker listing all j-scripts with
their descriptions. Typing any word searches by name, description, and
keywords. The full man page is shown in the right preview pane. Pressing
Enter outputs the selected script name with a trailing space. To get the
selection into your shell prompt buffer, source the included integration
file from ~/.zshrc:

    source ~/git/scripts/j.zsh

With this in place, typing j and pressing Enter opens the picker;
selecting a script places its name in the prompt ready for arguments.

"j new" can be run from any directory and opens $EDITOR with a compliant
template, only writing the file if it was changed. "j newman" works the same way for man page stubs.
"j list" reads the description line from each script header at runtime,
so there is no separate registry to keep in sync.

EXAMPLES

    j
        Open the interactive script picker.

    j list
        Print all j-scripts with their one-line descriptions.

    j help
        Print the command list.

    j new jMyTool
        Open a template for a new script called jMyTool.

    j man jPush
        Read the jPush man page in your pager.

    j newman jMyTool
        Open a man page stub for jMyTool in $EDITOR.
